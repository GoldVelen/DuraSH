# Security Policy

English | [中文](SECURITY.zh.md)

## Supported versions

DuraSH is a developer preview without a stable release line. Security fixes target the latest `main` branch only; older commits and downstream snapshots are not supported.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/GoldVelen/DuraSH/security/advisories/new) for suspected vulnerabilities, exposed credentials, or confidential conduct reports. Do not open a public issue or discussion before a coordinated fix is available.

Include the affected component and version, impact, minimal reproduction, and any known mitigations. Remove unrelated personal data and never attach live credentials, private logs, or production data.

## Response and disclosure

Maintainers will assess whether the report affects DuraSH-owned code, inherited DeepSeek Harness behavior, or another upstream project. DuraSH will coordinate a fix and public disclosure when the issue is in scope; reports that belong upstream will be redirected without publishing confidential details.

Reporter credit is optional and will be included only with the reporter's consent.
